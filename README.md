# Secure Member Portal

This is a multi-page web application built for a club project using Python and the Flask framework.

The primary goal of this project is to demonstrate a secure authentication system. 
It features a main homepage, a login page, and several "member-only" pages (like Search and Contact) that are protected. 
Users cannot access these private pages unless they are logged in.

 

## Core Features

User Authentication: A fully functional login and logout system.
Protected Routes: Key pages are inaccessible unless the user is authenticated.
Session Management:  Uses Flask sessions to track logged-in users.
Flash Messaging: Provides clear, non-intrusive feedback to the user.
Template Inheritance: A base template ensures a consistent design across all pages.
